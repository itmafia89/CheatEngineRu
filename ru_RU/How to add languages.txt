Создайте папку для языка вашей страны (названия папок должны соответствовать формату: en_US, nl_NL, ru_RU и т. д.).
Скопируйте файлы .po в соответствующую папку и приступайте к переводу.


Порядок выбора файлов:
  Если существует файл cheatengine.po, будет использоваться он.
  В противном случае будет выбран cheatengine-x86_64.po.
  Если и он отсутствует, будет использоваться cheatengine-i386.po.
  32-битная версия Cheat Engine может нормально работать с файлом перевода для 64-битной версии.

  Аналогичный порядок выбора применяется к файлам перевода обучения (Tutorial).


По умолчанию Cheat Engine использует язык операционной системы.
Вы можете изменить язык, добавив к параметрам запуска Cheat Engine --LANG langstr или -l langstr.


Редактирование файлов PO.
Существуют специальные программы для редактирования файлов .po, но их также можно изменять вручную.
msgid содержит исходный текст, а msgstr — переведённый текст.
Если msgstr пустой, будет отображаться исходный текст.

Некоторые строки отсутствуют в файле cheatengine.po, но присутствуют в lclstrconsts.po.
Файл lclstrconsts.po относится к библиотеке LCL, на основе которой построен графический интерфейс Cheat Engine.


Пользовательское название перевода:
Создайте в папке перевода файл name.txt и укажите в нём любое название, которое хотите отображать вместо кода языка.


Пользовательский Lua-скрипт для перевода:
Создайте в папке перевода файл init.lua. Код из этого файла будет автоматически выполняться при запуске Cheat Engine.
С его помощью можно изменять расположение элементов интерфейса или настраивать их привязки (anchors), чтобы освободить дополнительное место для переведённого текста.


----
Пример для нидерландского языка:
Создайте папку languages\nl_NL и переместите в неё файлы .po.

Затем переведите содержимое файлов.
Например:

До перевода:
#: mainunit.rscheatengine
msgid "Cheat Engine"
msgstr ""

После перевода:
#: mainunit.rscheatengine
msgid "Cheat Engine"
msgstr "Valsspeel motor"


(Это всего лишь пример. Пожалуйста, не переводите текст настолько буквально...)


Для проверки перевода запустите Cheat Engine с параметром:
--LANG nl_NL
